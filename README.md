# NAVORI — A Little Taste of Happiness ♡

A beautiful, unofficial fan-made website inspired by **NAV​​ORI**, a Thai dessert brand associated with Dunk Natachai.

Designed with a warm, elegant aesthetic using soft cream, peach, and brown tones to create a premium dessert-inspired experience.

### ✨ Features
- Elegant homepage with a welcoming hero section.
- NAVORI-inspired story and dessert collection.
- Special corner dedicated to Dunk Natachai.
- Aesthetic photo gallery.
- Smooth scrolling and interactive navigation.
- Fully responsive design for mobile and desktop.

### 🛠️ Built With
- HTML5
- CSS3
- JavaScript

### 🎨 Design Inspiration
A combination of minimal layouts, warm colours, elegant typography, and dessert-inspired visuals.
